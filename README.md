# 🌴 Sri Lanka Travel Guide

A simple and responsive **Sri Lanka Travel Guide** website created using **HTML, CSS, and JavaScript**. The website helps users explore popular destinations in Sri Lanka and provides useful travel information and links.

**Live Demo:** https://kaveeshamalindi.github.io/Sri-Lanka-Travel-Guide/

---

## Features

* 🏠 Home section with a hero image
* 📍 Popular Sri Lankan destinations
* 🔎 Destination search functionality
* 📖 View details about destinations
* 🌙 Dark mode / Light mode
* 📋 Travel information table
* 🔗 Useful travel links
* 📩 Contact form with validation
* ⬆️ Back-to-top button
* 📱 Responsive design for mobile devices
* 📅 Automatic current year in the footer
* ✨ Hover effects and interactive buttons

---

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Interactive functionality and form validation

---

## ⚙️ JavaScript Functionality

JavaScript is used to make the website interactive.

- **Explore Now**: Scrolls smoothly to the destinations section.
- **Search Destinations**: Allows users to search for destinations such as Kandy, Ella, and Galle.
- **View Details**: Displays additional information about each destination.
- **Dark Mode**: Allows users to switch between light and dark themes.
- **Contact Form**: Checks whether the required fields are completed and validates the email address.
- **Back to Top**: Provides a button to quickly return to the top of the page.
- **Automatic Year**: The footer automatically displays the current year using JavaScript.
